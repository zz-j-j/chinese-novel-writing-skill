# 中文小说创作（Agent Skill）

`novel-writing` 是面向中文小说创作的 Agent Skill，适用于构思、列大纲、续写、修订和审读。它把故事是否吸引人、人物是否真正参与、事件有没有后果、读者能否跟上，作为生成与修改的核心问题。

## 核心方法：读者牵引四问

这是一套供写作和审稿使用的轻量检查法，不是四幕结构或每场戏的固定公式：

1. 读者此刻在等什么、担心什么，或想弄明白什么？
2. 人物现在想做成什么，为什么重要？
3. 什么阻力迫使人物选择、改变办法或付出代价？
4. 场景结束后，什么已经改变或留下影响？

它和本 skill 的其他原则一起，帮助减少只有概念没有经历、人物只负责解释、情节反复原地打转等问题。即使某场戏不以冲突或悬念为重，也可以承担情绪、关系或节奏上的作用。

## 安装与使用

本项目采用开放的 Agent Skills 文件结构，核心指令位于 `SKILL.md`，配套细则位于 `references/`。支持加载 Agent Skills 的工具可按各自说明安装整个 `novel-writing` 文件夹；不要只复制 `SKILL.md`，否则相对引用的参考文件会缺失。不同 Agent 对技能发现、调用和引用文件的支持可能不同。

在 Codex 中，可将整个文件夹放入对应的 skills 目录：

- Windows：`%USERPROFILE%\.codex\skills\novel-writing`
- macOS/Linux：`~/.codex/skills/novel-writing`

新会话中可显式调用 `$novel-writing`，也可以直接提出小说任务。`agents/openai.yaml` 只提供 OpenAI/Codex 界面元数据；其他兼容工具可忽略该文件。

在其他工具中，请使用该工具对应的技能调用方式。可参考以下任务表达：

> 使用中文小说创作 Skill，先读大纲和前文，再续写第12章；保留现有视角和人物语气，检查新场景是否带来变化。

> 审读这三章，找出重复、难懂、人物缺少主动选择或后果没有延续的地方；先列问题，不改正文。

> 续写这部末世悬疑小说：先读已确认设定和前文，只采用相关题材参考；完稿后对账人物位置、伤势、道具和知情范围，未知信息不要自行补成事实。

> 复盘第二卷：检查本卷交付、人物变化和仍开放的主线；只对照我已经设定的伏笔回收计划，不要为每条线索擅自设期限。

> 精修这段成稿：先指出确实影响阅读的重复、概括或语气失配，再做最小范围修改，保留没问题的句子。

> 把这段改成更明显的常见 AI 叙述腔；保留事实和人物视角，别每段都套同一种结构。

> 按中文小说语境审读这段文字的模板化句式、比喻和标点：给出0–12分项审读分，引用文本证据并说明分数不是 AI 来源概率；只诊断，暂不改稿。

## 方法与边界

“读者牵引四问”是本 skill 用来讨论场景作用的轻量工具；题材档案提供可选期待与风险提示；长篇连续性和全书结构检查仅在相关任务中启用。成稿精修采用“文本证据—读者影响—局部修改—上下文复核”；长篇连续性可按需借助简短状态账。用户明确要求时，也可用模板化表达审读分标记句式、比喻和符号的编辑优先级；它不是 AI 来源检测或概率。上述方法都是辅助判断，不是固定配方。外部研究只作高层背景参考，资料链接和适用边界见[研究阅读笔记](references/reading-notes.md)。

本 skill 默认面向故事质量、清晰度和作品自身的声音；用户明确要求时，也可切换到显性 AI 腔。它不负责判定作者身份，也不承诺任何检测结果，可独立使用。

## 文件

- `SKILL.md`：主要创作指令
- `agents/openai.yaml`：Codex 界面显示信息
- `references/examples.md`：原创场景示例
- `references/prose-review.md`：成稿精修的诊断与局部编辑流程
- `references/style-signal-review.md`：句式、比喻、符号审读与模板化表达分
- `references/genre-profiles.md`：按需读取的中文小说题材期待与常见风险
- `references/story-state.md`：复杂长篇可选的设定与状态记录模板
- `references/continuity-check.md`：跨章节事实、状态和信息来源对账
- `references/longform-architecture.md`：卷级交付、全书线索与人物变化审读
- `references/ai-style-mode.md`：用户明确要求时采用的显性 AI 腔风格档位
- `references/reading-notes.md`：参考研究的简短摘要与边界
