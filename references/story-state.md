# 长篇小说状态账（可选）

当作品跨卷、人物多、时间线复杂，或反复出现设定/道具/人物去向对不上的问题时，可用这份轻量记录辅助续写与审稿。短篇、单线故事或已有清楚设定文档的作品不必重复建立。

它不是第二份正文，也不替作者决定剧情。记录只服务于后续判断；正文和作者确认过的设定仍是事实依据。若记录与正文冲突，应标出冲突来源并请作者裁定，不要悄悄把其中一方改成另一方。

## 记录依据与状态

- 区分“已接受正文/已确认设定”“大纲计划”“合理推断”和“未知”。大纲计划不等于已经发生，推断与未知不能作为确定事实约束后文。
- 尽量给关键记录加章节、段落、文件或设定条目等可回查来源。没有可靠来源时标注“待核实”，不要补造依据。
- 状态账是工作索引，不要求穷尽全书；续写或专项审读如何逐项核对，参见 [continuity-check.md](continuity-check.md)。
