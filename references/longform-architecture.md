# 卷级与全书结构审读

适用于跨卷、多线、长篇连载，或作者明确要求检查整体推进、伏笔和人物成长时。普通单章续写无需加载。这里的表格是帮助定位问题的可选工具，不是必须填满的模板。

## 卷级检查

按需回答：

- 本卷开端建立了什么主要期待、危险、关系变化或待解问题？
- 卷末实际交付了什么变化、阶段性答案或代价？哪些内容有意留到后续？
- 主角与重要配角的选择是否改变了局势？局势改变是否留下持续影响？
- 本卷与前后卷的连接是否清楚，还是只换了地点/副本而重复同一冲突？

这些是审读问题，不要求每卷采用相同结构，也不意味着每卷都要解决全部主线。

## 全书线索与承诺

只跟踪读者已被文本引导去期待、且后续仍可能影响理解的线索、问题和承诺。普通未解释细节不必自动登记为伏笔。

| 线索 / 承诺 | 首次来源 | 当前状态 | 作者计划的回收范围（如有） | 回收后的影响 / 备注 |
|---|---|---|---|---|
|  |  | 开放 / 推进中 / 已回收 / 已调整 / 已放弃 |  |  |

- 只有作者指定了回收章节或范围，才按计划提醒偏离或超期；没有计划时只记录为开放项，不制造期限。
- 回收可以是回答、反转、情感兑现、行动后果或明确放弃，不必总是揭晓谜底。
- 怀疑某条线索失联时，先回查正文与大纲并标证据；不要为了“回收率”强行把无关细节接成伏笔。

## 人物与能力变化

当人物成长、能力升级或权力变化是本书重要驱动力时，挑关键节点检查：起点状态、触发事件、人物选择、获得/失去的东西、后续行为变化。能力提升不必每次都有惩罚，但不能在关键冲突中无来源地越过本书已建立的限制。非升级型作品不需要画能力曲线。

稳定人物信息和即时状态继续记录在 [story-state.md](story-state.md) 中，不另建重复人物卡。若作者明确规定某人物不可死、某关系不可改或某事实不得提前揭露，按项目约束记录；不默认建立“死亡许可名单”。

## 连载副本与单元剧情差异

适用于无限流、单元副本、案件单元或其他连续更换主要场景的长篇。只有在连续单元开始重复同一冲突或脱困方式时才需要细查，不要求每卷使用全新的世界观或玩法。

- 可用轻量对照表比较相邻副本：入场原因、主要行动（救援、追踪、交易、围困、调查、寻找出口等）、关键线索如何获得、团队成员各自做什么、失败会失去什么、离开后留下什么影响。例子是可选方向，不是固定菜单。
- 差异要落在人物实际做的事和局势变化上。只换怪物、地点或规则名，而人物仍重复同一套猜规则、找漏洞、触发规则、脱困流程，读者仍会感到重复。若作者有意复用某一机制，检查它是否改变了用途、代价、掌控者或人物关系；有意回声可以保留，不必强行避开相似。
- 检查卷间转场是否由上一单元留下的现实后果、人物目标或未完成行动推动。任务通知、邀请或系统点名可以出现，但不应自动替代人物为何此刻行动的因果。
- 对恐怖或悬疑单元，可安排一次有依据的误判：人物根据当时掌握的线索作出合理但错误的判断，误判造成可见损失或风险；新证据迫使他们修正判断并改变办法。这是可选的推进手段，不是每卷必备节拍，也不应为制造刺激强行死人、受伤或惩罚角色。
- 可以延迟解释异常的完整机制。先让读者看清发生了什么、人物要做什么以及失败风险，再决定哪些原因暂不揭晓；保留疑问不等于让行动规则和现场关系都含混。若角色提出解释，要区分观察到的事实、暂时推测和已经验证的规则。
- 回看场景结尾时，留意动作或对话已经表达情绪、代价或主题后，旁白是否又重复总结一遍。若总结没有增加新信息或人物变化，可删或压短；不要把所有结尾都改成冷硬动作，也不要抹掉作品有意的主题回响。

## 使用时机与输出

可在卷纲完成、卷末复盘、长篇连续性检查或发现多条线索积压时启用。输出优先聚焦少数高影响事项：承诺是否兑现、局势是否真的变化、未决事项是否仍有功能、哪些内容需要作者裁定。不要为制造结构感，要求每章都有谜团、反转或强钩子；场景收尾可由动作、选择、情绪、后果、意象或安静停顿承担。
