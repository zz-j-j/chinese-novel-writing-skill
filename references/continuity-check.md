# 长篇连续性对账

在续写跨章节内容、审读多个章节或用户要求查矛盾时使用。短篇、单场景任务或与连续性无关的语言精修不必跑完整清单。若作品已有状态账，先读 [story-state.md](story-state.md)；状态账是索引，不替代回查正文、作者确认设定或明确的大纲计划。

## 对账步骤

1. **限定范围：** 明确本次章节/卷、相关人物和时间段。只追踪可能影响本次判断的事实，不试图重建整部作品。
2. **确认依据层级：** 依作者给出的正史优先级核对已接受正文、明确设定与计划大纲。不同来源互相冲突时先列明，不按文件新旧自行裁决。
3. **抽取状态：** 为关键项记录来源位置，并标注“已确认事实”“计划”“推断”或“未知”。推断和未知不能当作已确立事实；无依据时不补造。
4. **比对变化：** 检查当前章与之前状态是否冲突，或是否缺少足以解释变化的过程。角色故意撒谎、失忆、伪装、时间错位等可能是剧情机制，应检查文本是否支持，而非直接报错。
5. **分级交付：** 将发现分为“明确矛盾”“需要补桥/容易误读”“待核实”“无问题”。给出两端来源和读者影响；诊断请求只报告，用户授权后才改正文或设定。

## 五类连续性链

### 空间与行动

核对人物所在位置、移动路径、距离、通行条件、同行者及场景内物件位置。若人物突然换地点或完成不可能的行动，先检查是否有省略时间、转场或特殊能力依据。

### 时间与事件顺序

核对日期、时刻、持续时长、等待/旅行/恢复时间、昼夜和事件先后。区分叙述顺序与故事发生顺序；时间跳跃若有意，应确认读者能辨认。

### 人物、人数与知情范围

核对在场者、离场/失联/死亡者、人物身份与称谓，以及各角色何时、通过何种渠道获得信息。不能让人物使用尚未听到、看到、推断出或被告知的信息；群体人数变化也要有进入、离开或遗漏的依据。

### 伤势、能力、物资与道具

按情节影响追踪伤势、疲劳、能力限制、库存、关键物件持有人、损坏/消耗/归还情况。精确算数只在文本提供数量且数量影响行动时进行；来源没有给出数值时不擅自创造精确账目。

### 专名、术语与命名纪律

核对人名、称呼、地点、组织、物品、能力和规则名称是否稳定；检查明确的禁用名、改名决定或分卷命名约定。专名变化可能是化名、误称或剧情信息，需结合语境判断。
